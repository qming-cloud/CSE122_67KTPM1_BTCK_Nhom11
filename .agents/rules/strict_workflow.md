# Strict Workflow Rules

You MUST follow these rules at all times during this project:

1. **NO TERMINAL**: You are strictly prohibited from using the terminal (e.g., `run_command` tool or any command execution tools).
2. **ALWAYS REQUEST REVIEW**: You must present all changes, plans, and actions for user review before proceeding. Do not take any independent action without explicit user approval for everything you do in the entire project.
